FAQ

Questions, Answered

Is $49 the permanent price?

No. $49 is the launch price. The regular price is $79.

Do I need to UV unwrap my models?

Not for most materials, and never for imperfection layers. Fabrics need a UV map — MatricX warns you and creates one in a click. Trim sheets write the UVs for the faces you select.

Does it work in Cycles and EEVEE?

Yes. One exception: Edge Wear uses Blender's Bevel node, which only Cycles evaluates, so it shows in Cycles renders. Every other imperfection works in both engines.

Can I use my own textures, decals and trim sheets?

Yes. Import PBR texture sets as Custom Materials, add your own decal folders as libraries, and add your own trim sheets. MatricX does not ship trim sheets — the tool is there for yours.

Will 2.1 break my 2.0 scenes?

No. Materials you already applied are stored in your .blend files and keep rendering. Keep your 2.0 asset-pack folder in place so older decals still find their images.

Does it run on macOS and Linux?

Yes — one build for Windows, macOS and Linux. On Linux, extract the asset pack in your home folder and point MatricX to it with Locate Asset Pack (Flatpak included).

Add-on or Extension — which do I install?

Either; they are the same tool. Install one, not both. The Extension uses Blender's Get Extensions installer, the Add-on uses the classic Add-ons installer.
