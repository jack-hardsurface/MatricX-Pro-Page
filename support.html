  • Whether the asset pack shows "Ready" in Preferences
  • A screenshot or short screen recording
  • The exact steps that cause the problem
  • A small .blend file, if you can share one

Quick Fixes

The most common questions — try these first.

"Asset pack not connected"

Extract MatricX_Assets_2.1.0.zip, then in the MatricX panel click Locate Asset Pack and select the MatricX_Assets_2.1.0 folder. The parent folder or a subfolder works too.

Until a pack is connected, the "Looked in" line shows a default location inside the add-on folder. That's normal and changes once the pack is found.

"This is a 2.0.x asset pack"

You selected an older pack. MatricX PRO 2.1 needs MatricX_Assets_2.1.0.zip — download it from the store you bought from (Blender Market, Gumroad or Payhip), extract it, and select the new folder. Keep your old 2.0 folder where it is: decals in your 2.0 scenes still load their images from it.

Linux or Flatpak: the pack isn't found

Extract the pack to a normal folder in your home directory, such as ~/Downloads or ~/Documents — not inside the Flatpak .var folder — then use Locate Asset Pack.

Windows: the decal browser is empty

The pack is probably in a folder with a very long path. Move it somewhere short, such as D:\Assets\, and locate it again.

Edge Wear doesn't show up

Edge Wear uses Blender's Bevel node, which only Cycles renders. Switch the render engine to Cycles, or check it in a Cycles render. Every other imperfection works in EEVEE too.

A fabric material looks flat

Fabrics need a UV map. When MatricX warns you, click Create UV Map.

A pie menu shortcut clashes with another add-on

Turn the pie off, or change its shortcut, in Preferences → Add-ons → MatricX PRO.

Should I install the Add-on or the Extension?

Either — they're the same tool. Install one, never both. If you're upgrading, remove the old version and restart Blender first.
